# 《Work, Work》—— 魔兽争霸 AI 短片 · 完整制片包

> **Logline（一句话故事）**：杜隆塔尔的同一日黎明，一名兽人苦工与一名兽人战士，在两条战线上做着同一件事——为部落流汗，为部落流血。黄昏归营，他们在篝火旁相遇，把"For the Horde"还给了真正配得上它的人。
>
> **片长**：60 秒
> **基调**：好莱坞级 CG 史诗短片，纯魔兽争霸世界观
> **形式**：AI 生成（即梦 Seedream 2.0 + 即梦 Seedance 2.0）+ 真人配音 + Suno 配乐
> **主题**：英雄的史诗，是无数没有名字的人用同一种疲惫堆出来的
