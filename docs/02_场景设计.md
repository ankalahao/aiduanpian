## S1 · 杜隆塔尔黎明营地

### 设定

部落主基地奥格瑞玛**外围卫戍营地**，规模约 200 人，由木栅栏围合，周边是红土荒原与稀疏沙棘林。

### 美术参考

- 暴雪 CG《巫妖王之怒》开场杜隆塔尔晨景
- 《魔兽》(2016) 电影开场德拉诺营地
- 《魔戒》洛汗黄金宫殿外栅栏村落

### 地貌 / 建筑

| 元素 | 描述 |
|------|------|
| 地面 | 红黄色沙土，被无数脚印踩成硬路 |
| 建筑 | 黑色毡帐 + 骨刺图腾 + 木栅栏 + 号角塔 |
| 旗帜 | 部落巨型黑底红边狼头旗，6 米高，在风中猎猎 |
| 远景 | 奥格瑞玛巨大城墙剪影，露出尖塔 |
| 道具 | 武器架（斧、刀、弓）、磨刀石、水井、堆积的木桩 |

### 光照 / 色温

- **时间**：5:30 黎明
- **天气**：晨雾未散
- **光源**：地平线**血红朝阳**（低角度强光）+ 营地零星火把
- **色温**：3800K（暖橙红）
- **氛围**：静谧但即将爆发，雾气压低能见度

## S2 · 杜隆塔尔林场 + 金矿

### 设定

营地北侧 1 公里，**部落最大的木材 + 金矿混合产区**。上百名苦工同时作业，是部落战争机器的"心脏"。

### 美术参考

- 《魔戒》艾辛格炼炉俯拍（最重要参考）
- 《最后的武士》黎明村落劳作
- 暴雪 RTS 截图：War3 林场 + 金矿同框

### 地貌 / 建筑

| 元素 | 描述 |
|------|------|
| 林场 | 高大红木林，树高 30 米，树皮龟裂泛红 |
| 树桩 | 已伐区域，新鲜白色断面，木屑铺地半尺厚 |
| 金矿 | 露天阶梯式矿坑，黄褐土色，金石矿脉嵌入岩壁 |
| 木支架 | 矿口三层木质支架，挂吊桶和绳索 |
| 道具 | 成堆原木、金箱（带部落徽记）、磨石、水桶、绳索 |
| 远景 | 营地烟囱炊烟、远山轮廓 |

### 光照 / 色温

- **时间**：上午到中午
- **光源**：金黄色顶光，斜光透过树冠形成丁达尔效应
- **色温**：5500K（金黄）
- **氛围**：劳动节奏感、汗水蒸腾、木屑漫天

### 关键视觉点

- **群体劳作的"史诗感"**：俯拍角度，上百苦工同时挥斧的整齐节拍
- **个体特写的"颗粒感"**：木屑慢动作、汗珠滴落、肌肉颤抖
- **大场面参考构图**：艾辛格炼炉俯拍 + 古埃及金字塔工地壁画

## S3 · 贫瘠之地边境战场

### 设定

杜隆塔尔与南贫瘠之地交界处，部落与人族（达拉然遗党 / 拉文霍德）的常年冲突区。

### 美术参考

- 《魔戒》圣盔谷决战（雨夜版反向 → 干燥日间版）
- 《300 勇士》温泉关列阵
- 《最后的武士》最后冲锋
- 《魔兽》(2016) 黑色沼泽战役

### 地貌

| 元素 | 描述 |
|------|------|
| 地面 | 干裂草黄土黄，大量脚印、车辙、血迹 |
| 障碍 | 断裂的巨石阵、被推倒的人族哨塔、烧黑的木桩 |
| 远景 | 卡利姆多大陆典型干燥山脉，地平线起伏 |
| 道具 | 散落的人族盾牌、断箭、倒伏的旗帜（部落 vs 联盟混杂） |
| 天空 | 浓密乌云聚集（萨尔即将施法的预兆） |

### 光照 / 色温

- **天气**：阴沉，乌云密布

- **色温**：6500K（冷青带血红）
- **氛围**：压抑、肃杀、雷雨将至

### 关键视觉点

- **大场面**：千军万马层级，参考魔戒洛汗冲锋构图
- **细节**：兵器碰撞火花、血雾、断刃、护甲反光

## S4 · 黄昏 · 双线归营路

### 设定

A 路：林场出口的红土小径，B 路：战场归途的山脊小径。两条路**共享同一片夕阳和色温**，但**人物姿态、构图重心、机位高度都刻意不同**——同一片夕阳下，两种不同的休息。

### 美术参考

- 《最后的武士》武士归乡黄昏
- 《魔戒》刚铎将士归来
- 《1917》黄昏奔跑长镜头
- 黑泽明《七武士》收尾

### 地貌 / 光照

| 元素 | 描述 |
|------|------|
| 时间 | 19:00 日落 |
| 光源 | 地平线橙红巨大夕阳，长投影 |
| 色温 | 4200K，**两线在此处色温收敛（这是唯一对位项）** |
| 风 | 中等强度，旗帜 / 头发飘动 |

### 关键视觉点

- **#15 战士**：立姿剪影，拄战斧守望姿态，构图重心**纵向**（人物占画面纵向 70%）
- **#16 苦工**：坐姿剪影（坐在原木上撑膝盖），劳动者歇息姿态，构图重心**横向**（坐姿+地上金箱占画面横向 60%）
- **共享元素**：同一片夕阳、同一色温（4200K）、同一长投影方向、同一晚风
- **差异元素**：姿态、机位高度（#16 比 #15 低 50cm）、构图重心、武器位置（拄手 vs 杵地）
- 这是全片**视觉最美**的两个镜头，必须做到电影海报级——但**绝不复制构图**

## S5 · 营地篝火夜

### 设定

回到营地中心广场，一座大型石砌篝火坑周围，士兵和苦工**分两半**坐着烤火、疗伤、吃肉、喝酒。

这是全片**唯一让两条线物理交汇的空间**。

### 美术参考

- 《魔戒》洛汗篝火夜
- 《最后的武士》武士村庄夜晚
- 暴雪 CG《熊猫人之谜》开场茶馆光影

### 地貌 / 道具

| 元素 | 描述 |
|------|------|
| 篝火坑 | 1.5 米直径石砌火坑，火焰高 1 米 |
| 周围 | 木桩座、皮垫、堆积的兽皮 |
| 远景 | 营帐内暖黄光、远处巡夜哨兵剪影 |
| 道具 | 肉干架、水皮囊、绷带堆、酒坛、磨刀石 |
| 天空 | 深蓝夜空，有星，无月或半月 |

### 光照 / 色温

- **主光**：篝火（1900K，暖橙红）
- **副光**：月光 + 星光（7000K，冷蓝）
- **氛围**：**双补色**——暖橘人脸 + 冷蓝背景，这是好莱坞夜戏黄金公式
- **粒子**：火星向上飘散、烟雾扭曲热气

### 关键视觉点

- 镜头 #17 是全片**情感最高点**，光影必须做对：
  - 战士走过时，**火光从右侧打过来**，半边脸暖光半边脸暗影（英雄式打光）
  - 苦工接过肉干时，**火光从下打到他眼里**，泪光闪烁不流出
  - 两人对视时，篝火在两人之间形成**自然焦平面分隔**

### 双线呼应剪辑的"差异规则"（与 v1 完全相反）

A 线（苦工）和 B 线（战士）的镜头要做到："**两个角色看起来像两个真实独立的兽人个体；构图刻意不同；只在情绪击点和声音节奏上共振。**"

> 详见 [03_剧情与剧本.md](03_剧情与剧本.md) 创作哲学段、[04_视听风格.md](04_视听风格.md) 双线呼应剪辑总纲。

#### 必须做差异化的（4 项）

1. **角色个体差异**：年龄（42 vs 35）、身高（2.05m vs 2.30m）、肤色（橄榄绿 vs 翡翠绿）、发型（独辫 vs 顶髻）、动作习惯（节省体力的迟缓 vs 爆发力强）——每一镜都体现至少 2 项
2. **构图刻意区分**：A 镜俯拍 / B 镜平拍；A 镜立姿 / B 镜坐姿；A 镜侧拍 / B 镜后拍；A 镜横向重心 / B 镜纵向重心——具体见每镜 prompt
3. **机位高度差**：洛卡身高 2.30m 与格罗什 2.05m，对应的肩高 / 眼平线机位**必须有 25cm 差异**
4. **武器形制 / 服装磨损度**：劈柴斧（钝、缠破布、有节疤）vs 战斧（4 缺口、皮革柄、有铆钉）；粗麻短褂赤脚 vs 黑铁板甲铁靴

#### 允许做共振的（4 项，且只在这些层面）

1. **情绪击点**：两条线在情绪曲线上的爆发点 / 低谷点严格同步
2. **主题动作**：都"握紧"、都"咬牙"、都"流汗"、都"望向同一片夕阳"——但**姿态不同**
3. **声音节奏**：呼吸节奏、闷哼节奏、脚步节奏可以呼应（音桥见第六章音轨表）
4. **BGM 节拍**：双线在 BGM 同一拍点切换

#### 唯一允许的"图像对位锚点"

全片只有 1 处可以做严格视觉对位：**镜头 #5 双手特写**——两双手都因用力而**指节发白、青筋隆起**。其他所有"对组镜"必须靠主题呼应，不靠图像复制。
