## S1 · 杜隆塔尔黎明营地

### 设定

部落主基地奥格瑞玛**外围卫戍营地**，规模约 200 人，由木栅栏围合，周边是红土荒原与稀疏沙棘林。

### 美术参考

- 暴雪 CG《巫妖王之怒》开场杜隆塔尔晨景
- 《魔兽》(2016) 电影开场德拉诺营地
- 《魔戒》洛汗黄金宫殿外栅栏村落

### 地貌 / 建筑

| 元素 | 描述 |
|------|------|
| 地面 | 红黄色沙土，被无数脚印踩成硬路 |
| 建筑 | 黑色毡帐 + 骨刺图腾 + 木栅栏 + 号角塔 |
| 旗帜 | 部落巨型黑底红边狼头旗，6 米高，在风中猎猎 |
| 远景 | 奥格瑞玛巨大城墙剪影，露出尖塔 |
| 道具 | 武器架（斧、刀、弓）、磨刀石、水井、堆积的木桩 |

### 光照 / 色温

- **时间**：5:30 黎明
- **天气**：晨雾未散
- **光源**：地平线**血红朝阳**（低角度强光）+ 营地零星火把
- **色温**：3800K（暖橙红）
- **氛围**：静谧但即将爆发，雾气压低能见度

## S2 · 杜隆塔尔林场 + 金矿

### 设定

营地北侧 1 公里，**部落最大的木材 + 金矿混合产区**。上百名苦工同时作业，是部落战争机器的"心脏"。

### 美术参考

- 《魔戒》艾辛格炼炉俯拍（最重要参考）
- 《最后的武士》黎明村落劳作
- 暴雪 RTS 截图：War3 林场 + 金矿同框

### 地貌 / 建筑

| 元素 | 描述 |
|------|------|
| 林场 | 高大红木林，树高 30 米，树皮龟裂泛红 |
| 树桩 | 已伐区域，新鲜白色断面，木屑铺地半尺厚 |
| 金矿 | 露天阶梯式矿坑，黄褐土色，金石矿脉嵌入岩壁 |
| 木支架 | 矿口三层木质支架，挂吊桶和绳索 |
| 道具 | 成堆原木、金箱（带部落徽记）、磨石、水桶、绳索 |
| 远景 | 营地烟囱炊烟、远山轮廓 |

### 光照 / 色温

- **时间**：上午到中午
- **光源**：金黄色顶光，斜光透过树冠形成丁达尔效应
- **色温**：5500K（金黄）
- **氛围**：劳动节奏感、汗水蒸腾、木屑漫天

### 关键视觉点

- **群体劳作的"史诗感"**：俯拍角度，上百苦工同时挥斧的整齐节拍
- **个体特写的"颗粒感"**：木屑慢动作、汗珠滴落、肌肉颤抖
- **大场面参考构图**：艾辛格炼炉俯拍 + 古埃及金字塔工地壁画

## S3 · 贫瘠之地边境战场

### 设定

杜隆塔尔与南贫瘠之地交界处，部落与人族（达拉然遗党 / 拉文霍德）的常年冲突区。

### 美术参考

- 《魔戒》圣盔谷决战（雨夜版反向 → 干燥日间版）
- 《300 勇士》温泉关列阵
- 《最后的武士》最后冲锋
- 《魔兽》(2016) 黑色沼泽战役

### 地貌

| 元素 | 描述 |
|------|------|
| 地面 | 干裂草黄土黄，大量脚印、车辙、血迹 |
| 障碍 | 断裂的巨石阵、被推倒的人族哨塔、烧黑的木桩 |
| 远景 | 卡利姆多大陆典型干燥山脉，地平线起伏 |
| 道具 | 散落的人族盾牌、断箭、倒伏的旗帜（部落 vs 联盟混杂） |
| 天空 | 浓密乌云聚集（萨尔即将施法的预兆） |

### 光照 / 色温

- **时间**：上午到中午（与林场严格同时）
- **天气**：阴沉，乌云密布
- **光源**：穿过乌云的狭窄光柱，戏剧性边缘光
- **色温**：6500K（冷青带血红）
- **氛围**：压抑、肃杀、雷雨将至

### 关键视觉点

- **大场面**：千军万马层级，参考魔戒洛汗冲锋构图
- **细节**：兵器碰撞火花、血雾、断刃、护甲反光
- **萨尔暗示**：远景高坡剪影，举锤召唤雷电（仅 #11 一镜）

## S4 · 黄昏 · 双线归营路

### 设定

A 路：林场出口的红土小径，B 路：战场归途的山脊小径。两条路在视觉构图上**严格对称**。

### 美术参考

- 《最后的武士》武士归乡黄昏
- 《魔戒》刚铎将士归来
- 《1917》黄昏奔跑长镜头
- 黑泽明《七武士》收尾

### 地貌 / 光照

| 元素 | 描述 |
|------|------|
| 时间 | 19:00 日落 |
| 光源 | 地平线橙红巨大夕阳，长投影 |
| 色温 | 4200K，**两线在此处色温收敛** |
| 风 | 中等强度，旗帜 / 头发飘动 |

### 关键视觉点

- **剪影构图**：两人都背对夕阳，拄武器站立
- **同机位 / 同焦段 / 同高度**：A 镜和 B 镜可以叠化都不违和
- 这是全片**视觉最美**的两个镜头，必须做到电影海报级

## S5 · 营地篝火夜

### 设定

回到营地中心广场，一座大型石砌篝火坑周围，士兵和苦工**分两半**坐着烤火、疗伤、吃肉、喝酒。

这是全片**唯一让两条线物理交汇的空间**。

### 美术参考

- 《魔戒》洛汗篝火夜
- 《最后的武士》武士村庄夜晚
- 暴雪 CG《熊猫人之谜》开场茶馆光影

### 地貌 / 道具

| 元素 | 描述 |
|------|------|
| 篝火坑 | 1.5 米直径石砌火坑，火焰高 1 米 |
| 周围 | 木桩座、皮垫、堆积的兽皮 |
| 远景 | 营帐内暖黄光、远处巡夜哨兵剪影 |
| 道具 | 肉干架、水皮囊、绷带堆、酒坛、磨刀石 |
| 天空 | 深蓝夜空，有星，无月或半月 |

### 光照 / 色温

- **主光**：篝火（1900K，暖橙红）
- **副光**：月光 + 星光（7000K，冷蓝）
- **氛围**：**双补色**——暖橘人脸 + 冷蓝背景，这是好莱坞夜戏黄金公式
- **粒子**：火星向上飘散、烟雾扭曲热气

### 关键视觉点

- 镜头 #17 是全片**情感最高点**，光影必须做对：
  - 战士走过时，**火光从右侧打过来**，半边脸暖光半边脸暗影（英雄式打光）
  - 苦工接过肉干时，**火光从下打到他眼里**，泪光闪烁不流出
  - 两人对视时，篝火在两人之间形成**自然焦平面分隔**

## 跨场景视觉规则（重要）

### 调色对位

| 场景 | LUT 倾向 | 主色 | 辅色 |

| S1 黎明 | Orange-Brown | 朝阳橙 | 雾蓝 |
| S2 林场 | Golden Hour | 蜂蜜金 | 木褐 |
| S3 战场 | Teal-Rust | 冷青 | 血锈 |
| S4 黄昏 | Magic Hour | 橙红 | 紫蓝 |
| S5 篝火 | Orange-Teal 双补色 | 篝火橙 | 夜空蓝 |

### 镜像剪辑的"形似规则"

A 线（苦工）和 B 线（战士）的镜头要做到："**换掉服装和环境后，构图、运镜、节奏完全相同**"。

具体落地办法：
1. **同焦段**：两镜都用 50mm 中景或 85mm 特写
2. **同机位高度**：人物的眼睛位于画面同一水平线
3. **同时长**：两镜都是 2.5–3 秒
4. **同节奏点**：动作的"砍下"、"溅出"、"跪下"必须落在同一帧位
