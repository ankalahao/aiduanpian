# 03 · 剧情与完整剧本

> 60 秒短片的**结构密度**比长片更苛刻——每一秒都要承担情感或信息任务。
> 本片采用**严格三幕 + 双线平行 + 镜像剪辑**的复合结构。

---

## 一、剧作工程

### 1. Logline（一句话故事）

> 杜隆塔尔的同一日黎明到夜晚，一名兽人苦工与一名兽人战士，在两条战线上做着同一件事——为部落流汗、流血。当他们在篝火旁相遇，"For the Horde"这句话才第一次被还给真正配得上它的人。

### 2. 主题陈述（Theme Statement）

> **真正的部落，不是英雄一个人的史诗，而是无数无名者用同一种疲惫共同写下的一行字。**

主题不通过台词说出，**只通过镜像剪辑的视觉对位**让观众自己得出结论。

### 3. 戏剧问题（Dramatic Question）

> "For the Horde" 这句口号，到底属于谁？

短片用 60 秒回答：**属于格罗什，也属于洛卡，属于所有流汗流血的人。**

### 4. 情感曲线

```
情绪强度
   ↑
10 |                                            ★ 篝火对视
 9 |                                          ★
 8 |                  ★ 出征 + 林场             ★
 7 |               ★         ★ 雷霆萨尔
 6 |            ★ 镜像砍击             ★ 黄昏剪影
 5 |         ★                       ★
 4 |     ★ 集结                    ★
 3 |  ★ 黎明
 2 |★
 1 |________________________________________
   0   10   20   30   40   50   60   秒
   |   一幕   |    二幕    |  三幕  |
   | 0–15s  |   15–48s   | 48–60s |
```

## 二、三幕结构

### 第一幕（0–15 秒）· 黎明 · 出工

**功能**：建立世界、建立两个角色、建立"双线平行"的视觉语法

| 镜头 | 戏剧任务 |
|------|---------|
| #1 黎明全景 | 建立时间、地点、史诗感 |
| #2 号角 | 唤醒——叙事开关被按下 |
| #3 苦工领斧 | 建立 A 线主角及阵营 |
| #4 战士佩刀 | 建立 B 线主角及阵营 |
| #5 双手特写镜像 | **第一次确立"镜像剪辑"语法**——观众潜意识接受 A=B |

**末尾情绪**：宁静中蕴含张力，号角余音未散

### 第二幕（15–48 秒）· 双线劳作 / 厮杀

**功能**：把"日常"和"战场"做到极致，让镜像剪辑产生压倒性的情感重量

#### 第二幕 - 上半场（15–30 秒）：力量爆发

| 镜头 | 戏剧任务 |
|------|---------|
| #6 出征大场面 | **CG 高潮 1**——千军万马，史诗感拉满 |
| #7 林场大场面 | **CG 高潮 2**——苦工劳作的史诗感（与 #6 等量） |
| #8 镜像砍击 | **镜像剪辑高潮**——一斧 = 一刀，主题视觉化 |
| #9 战士受伤 | 引入"代价"——英雄不是无敌的 |
| #10 苦工受伤 | 镜像——苦工流的也是血（同一种） |

#### 第二幕 - 下半场（30–48 秒）：意志坚持

| 镜头 | 戏剧任务 |
|------|---------|
| #11 雷霆萨尔 | **戏剧高点**——魔兽迷彩蛋 + 暗示天意 |
| #12 苦工抬头看雷雨 | 跨线呼应——他与战场之间有了"无形连接" |
| #13 苦工扛金箱 | 沉重前行——意志主题 |
| #14 战士背伤兵 | 镜像——同样的沉重，同样的前行 |

**末尾情绪**：极度疲惫但都没倒下

### 第三幕（48–60 秒）· 黄昏 / 篝火 · 收束

**功能**：让 12 秒承载整片的情感重量

| 镜头 | 戏剧任务 |
|------|---------|
| #15 战士黄昏剪影 | 视觉静止——情绪开始沉淀 |
| #16 苦工黄昏剪影 | 镜像收束——A=B 的视觉论证完成 |
| #17 篝火递肉干 | **情感最高点**——两条线终于在物理空间相遇 |
| #18 双人特写台词 | **主题揭示**——"Work, work" / "For the Horde" |
| 黑屏字幕 | **主题落地**——For those who built it |

## 三、完整分镜剧本

### 格式说明

每个镜头包含：
- **景别 / 焦段**
- **运镜**
- **画面描述**
- **声音**（对白 / 音效 / 音乐）
- **时长 / 起止时间码**
- **情绪关键词**

---

### 镜头 #1 · 黎明全景

| 项 | 内容 |
|---|---|
| 景别 | 极远景 |
| 焦段 | 24mm 广角 |
| 运镜 | **慢推**（2 秒内从 100% 推到 90%） |
| 时长 | 0:00 – 0:03（3 秒） |
| 情绪 | 史诗、宁静、蓄势 |

**画面**：
杜隆塔尔黎明。镜头从极高处俯瞰红土荒原，一道地平线，一轮血色朝阳贴着地平线升起。前景是巨大的部落狼头黑红旗在风中猎猎，旗杆木质粗糙带裂纹。营地黑色毡帐零星分布，晨雾贴地流动。远处奥格瑞玛城墙剪影。

**声音**：
- 远号角声（低、长、苍凉）
- 风声（中等强度）
- BGM：**蒙古喉音 + 单一鼓点**起拍

---

### 镜头 #2 · 号角手

| 项 | 内容 |
|---|---|
| 景别 | 中景 |
| 焦段 | 35mm |
| 运镜 | 固定（仰角约 15°） |
| 时长 | 0:03 – 0:05（2 秒） |
| 情绪 | 唤醒、肃穆 |

**画面**：
号角塔顶端，一名中年女兽人号角手鼓腮吹号。她戴狼牙项链，皮肤深绿，呼出的白雾在朝阳逆光中散开。镜头微微仰角，号角金属雕花清晰可见。背景是逐渐亮起的天空，云层被阳光镶上金边。

**声音**：
- 号角长鸣（升至最高音）
- 喉音 BGM 加入弦乐铺底

### 镜头 #3 · A 线 · 苦工领斧（跟拍）

| 项 | 内容 |
|---|---|
| 景别 | 跟拍中景 |
| 焦段 | 35mm |
| 运镜 | **Steadicam 跟拍**（侧后方跟随） |
| 时长 | 0:05 – 0:08（3 秒） |
| 情绪 | 日常、机械、沉默 |

**画面**：
苦工大队从营地军械库领取劈柴斧，一字队列。**主角格罗什**走在队列中段（左眉疤、独辫、赤脚），他面无表情接过斧头，掂了掂分量，扛上左肩。其他苦工动作几乎一致。脚下扬起红土。镜头与他保持 2 米距离侧后方跟随。

**声音**：
- 金属交接声（哐当哐当）
- 苦工低声："Yes？"（魔兽原版语音，疲惫版）
- 集体脚步声
- BGM 加入低音提琴

**字幕**：（无）

### 镜头 #4 · B 线 · 战士佩刀（跟拍）

| 项 | 内容 |
|---|---|
| 景别 | 跟拍中景 |
| 焦段 | 35mm |
| 运镜 | **Steadicam 跟拍**（与 #3 镜像对称——侧前方跟随） |
| 时长 | 0:08 – 0:11（3 秒） |
| 情绪 | 整肃、即将爆发 |

**画面**：
战士小队从同一个军械库领取双手战斧，一字队列，铁靴整齐踏地如鼓点。**主角洛卡**走在队列前段（右脸纹身、缺口战斧），他接过战斧，斧柄一抡，扛上右肩。腰间布袋微微鼓起（暗示肉干）。

**声音**：
- 重型铁器碰撞（更沉）
- 整齐铁靴踏地
- 战鼓声轻轻加入
- BGM 加入男声合唱低音

### 镜头 #5 · 镜像特写 · 双手握紧

| 项 | 内容 |
|---|---|
| 景别 | 极近特写（双手） |
| 焦段 | 85mm |
| 运镜 | 固定 + 极慢推 |
| 时长 | 0:11 – 0:13（2 秒） |
| 情绪 | 宣告主题 |

**画面**：
**前 1 秒**：苦工格罗什粗糙的手握紧劈柴斧木柄，关节发白，破布缠柄清晰可见。
**后 1 秒**：战士洛卡布满疤痕的手握紧战斧皮革柄，关节发白，皮革磨损可见。
**两个画面构图、机位、焦距、握柄角度完全一致**——只有手和武器不同。

**声音**：
- 皮革握紧声 / 木柄吱呀声（叠化过渡）
- BGM：鼓点开始变密

**导演笔记**：
> 这是全片"镜像剪辑语法"的**官方宣告镜头**。观众的潜意识从这一刻开始，已经在期待"接下来 A=B"的对位。

### 镜头 #6 · B 线 · 部落出征大场面

| 项 | 内容 |
|---|---|
| 景别 | 极远景 → 鸟瞰 |
| 焦段 | 24mm 广角 |
| 运镜 | **升降机大幅运动**：从地面战士冲锋的视角，跟随 1 秒后**陡然升起**至俯瞰 3 秒 |
| 时长 | 0:13 – 0:17（4 秒） |
| 情绪 | 史诗爆发、压倒性 |

**画面**：
镜头起在地面，跟拍一名狼骑兵从奥格瑞玛大门冲出。运镜陡然向上飞升，画面拉开——千军万马的部落大军从大门蜂拥而出，狼骑兵、巨魔战士、双足飞龙编队、巨型攻城车，红土被踏起漫天烟尘，黑红旗帜如海浪。地平线上是燃烧军团旗号或人族联军的远影。

**导演笔记**：
> 直接对标《魔戒》洛汗骑兵冲锋助洛拉斯解围的镜头。
> 这是 **CG 高潮 1**，必须做到 1080p 看不到任何 AI 瑕疵。
> Veo 3 抽卡预算可以单镜砸到 30 次。

**声音**：
- 战吼震天（千人合声）
- 战鼓密集
- 狼嚎、马蹄、金属磕碰
- BGM 进入**主题段 A · 雄壮出征**

---

### 镜头 #7 · A 线 · 林场大场面

| 项 | 内容 |
|---|---|
| 景别 | 鸟瞰俯拍 |
| 焦段 | 35mm（高空） |
| 运镜 | **固定俯拍 → 缓慢推近** |
| 时长 | 0:17 – 0:21（4 秒） |
| 情绪 | 史诗劳作、震撼 |

**画面**：
高空俯拍杜隆塔尔大林场。上百名兽人苦工同时挥斧，红木林被开出宽阔伐区，金矿坑像一个巨大的伤口嵌在地面，木支架像蜘蛛网。烟尘和木屑在金黄光柱中漂浮。镜头缓慢推近一个工区，可以看到苦工们整齐如鼓点的劳作节奏——**视觉节奏与 #6 出征大军完全同步**。

**导演笔记**：
> 这是 **CG 高潮 2**——而且是**全片最重要的视觉论点**：
> "苦工的劳作和战士的冲锋，在体量、节奏、史诗感上是平等的"
> 这一镜如果做不到与 #6 等量级，整部片的立意就垮了。
> 必须出图、出视频时和 #6 反复对照，**两镜可以叠化都不违和**。

**声音**：
- 千斧齐落（如同战吼）
- 劳动号子（兽人沙哑低吼，类似纤夫号子）
- 金石撞击声
- BGM 持续主题段 A，但鼓点变成**劳作节奏**

### 镜头 #8 · 镜像砍击（核心主题镜）

| 项 | 内容 |
|---|---|
| 景别 | 极近特写 |
| 焦段 | 85mm 微距 |
| 运镜 | 固定 + **120fps 升格慢动作** |
| 时长 | 0:21 – 0:24（3 秒，分 8A + 8B 各 1.5 秒） |
| 情绪 | 主题揭示、暴力诗意 |

**画面**：

**8A（0:21 – 0:22.5）**：
极特写——格罗什的劈柴斧刃**刚刚切入红木树干**的瞬间。木屑炸裂飞向镜头，慢动作下每一片木屑清晰可见。汗珠从他眉骨疤痕旁滑落，被镜头捕获飞溅。背景金黄丁达尔光柱。

**8B（0:22.5 – 0:24）**：
极特写——洛卡的战斧刃**刚刚切入人族士兵护甲**的瞬间。血雾炸裂飞向镜头，慢动作下每一滴血珠清晰可见。汗珠从他纹身脸颊滑落，被镜头捕获飞溅。背景冷青烟尘。

**两镜构图、机位、运镜方向、慢动作速率完全一致**——但 8A 是黄金光，8B 是冷青光；8A 飞木屑，8B 飞血雾。

**声音**：
- 8A：劈砍木声（清脆爆裂）
- 8B：金属穿透甲胄声（沉闷撕裂）
- **音桥**：8A 的劈砍声末尾**直接切到 8B 的撕裂声**——听觉上是一个动作的两个回声
- BGM 鼓点重击

**导演笔记**：
> **这是全片在导演层面最核心的一镜**。
> 如果这一镜做对了，整片立意就成了。
> 必须 60 帧以上慢动作，**音桥必须用同一帧切换**。

### 镜头 #9 · B 线 · 战士受伤

| 项 | 内容 |
|---|---|
| 景别 | 中景 |
| 焦段 | 50mm |
| 运镜 | 微微手持晃动 |

### 镜头 #11 · B 线 · 雷霆萨尔（彩蛋）

| 项 | 内容 |
|---|---|
| 景别 | 极远景 |
| 焦段 | 35mm |
| 运镜 | 仰角，固定 |
| 时长 | 0:30 – 0:33（3 秒） |
| 情绪 | 神性降临 |

**画面**：
战场上空乌云汇聚成漩涡。一道**白蓝色巨型闪电**从云层中劈下。在闪电照亮的一瞬间，远景一座高坡上隐约可见一个**双手举锤的剪影**——萨尔——只是一个轮廓，没有正脸。

**声音**：
- 雷鸣（巨大、压倒一切）
- 静音 0.5 秒（雷后回响）
- 风声呼啸

**导演笔记**：
> **彩蛋不能太明显**——萨尔出现时间不超过 0.6 秒，且必须是剪影。
> 资深玩家会激动，普通观众也不会出戏。

### 镜头 #12 · A 线 · 苦工抬头看雷雨

| 项 | 内容 |
|---|---|
| 景别 | 中近景（仰拍） |
| 焦段 | 50mm |
| 运镜 | 慢慢仰起跟随他抬头的动作 |
| 时长 | 0:33 – 0:35（2 秒） |
| 情绪 | 跨线连接 |

**画面**：
林场中。格罗什放下手中的斧头，抬头望天。远处的**雷声从战场传来**，他听到了。雨点开始落在他脸上，他眨了眨眼。这是全片他**第一次抬头**——之前所有镜头他都在低头干活。

**声音**：
- 远雷（明显比 #11 弱，是回响）
- 雨点落在皮肤上的轻响
- BGM 弦乐升高一个音

**导演笔记**：
> 这一镜是 A 线和 B 线**第一次产生跨线呼应**——两条平行线开始有了感应。
> 观众这时候应该已经隐约感到"他们之间有什么连接"。

### 镜头 #14 · B 线 · 战士背伤兵（镜像）

| 项 | 内容 |
|---|---|

### 镜头 #17 · 篝火 · 递肉干（情感最高点）

**0:50 – 0:51**：洛卡回头看格罗什。半边脸被火光照成暖橘，半边脸暗影。

**0:51 – 0:52**：他从腰间布袋里掏出一块**风干肉干**（这是布袋里最后一块），沉默地递过去。

**导演笔记**：

> 演员表演（即使是 AI）必须做到：

> 这两种情绪是好莱坞表演的最高难度，AI 抽卡时要反复挑选。
