# 03 · 剧情与完整剧本

> 60 秒短片的**结构密度**比长片更苛刻——每一秒都要承担情感或信息任务。
> 本片采用**严格三幕 + 双线平行 + 主题呼应剪辑**的复合结构。

---

## 创作哲学：主题呼应剪辑（Thematic Match Cut）—— 不是图像镜像

> 这是本片**最核心的视觉哲学**，必须先讲清楚，否则后面所有分镜都会被误读成 MV / 概念片。

### "图像镜像"（Graphic Match Cut） vs "主题呼应"（Thematic Match Cut）

| 类型 | 例子 | 语法属性 |
|------|------|---------|
| 图像镜像 | 库布里克《2001 太空漫游》骨头 → 飞船 / 苹果对位广告 | **MV / 广告 / 概念片**——刻意设计感强，观众"看到设计" |
| 主题呼应 | 《教父》洗礼 + 谋杀对剪 / 《魔戒》弗罗多挣扎 + 阿拉贡黑门大战 | **真正的电影叙事**——构图完全不同，但情绪击点严格同步 |

**本片走主题呼应路线，绝不做图像镜像。**

### 为什么不做"严格 AB 镜像"

1. **现实感**：现实里不会有两个人长得一样、动作一样、姿势一样
2. **角色尊严**：格罗什和洛卡是两个独立的灵魂，不是同一个人的两面镜子
3. **观众沉浸**：图像复制会让观众出戏（"这是设计过的"），主题呼应才让观众相信"这是真实发生的两条人生"
4. **电影 vs MV 的分水岭**：CG 短片要做电影感，就必须放弃 MV 那种 design-heavy 的对位剪辑

### 双线呼应剪辑的"4 个落点"

A 线（苦工）和 B 线（战士）的镜头**只在以下 4 个层面共振**，构图、姿态、机位**主动追求差异**：

1. **情绪节奏对位**：两条线在情绪曲线上的爆发点、低谷点严格同步
2. **主题动作对位**：都"握紧"、都"咬牙"、都"流汗"、都"望向同一片夕阳"——但姿态不同
3. **声音节奏对位**：呼吸节奏、闷哼节奏、脚步节奏可以呼应
4. **物理状态对位**：都泥土沾身、都汗渍盐渍、都疲惫——但伤痕、动作、表情各异

### 角色差异化的"5 个抓手"

为了让两个角色**像两个真实的兽人个体**，每个对组镜头必须体现至少 2 项差异：

| 维度 | 格罗什（苦工 · 42 岁） | 洛卡（战士 · 35 岁） |
|------|--------------------|------------------|
| 体型 | 矮（2.05m）、长期负重略弓背、肌肉是劳动型紧实 | 高（2.30m）、挺立、肌肉是战斗型 V 字肩 |
| 动作习惯 | 节省体力的迟缓、习惯撑腰歇口气、动作有韧性 | 爆发力强、起势快、动作有节制感 |
| 受伤反应 | 被动 / 惊愕 / 趔趄瘫坐 / "又一天的伤" | 主动 / 咬牙 / 单膝跪地拄武器 / "熟悉的疼" |
| 休息姿态 | 坐 / 倚靠 / 撑膝 / 弯腰（劳动者的歇法） | 站 / 拄武器 / 挺胸 / 仰头（军人的歇法） |
| 表情节奏 | 慢、压抑、笑要憋很久才出来 | 快、外放、点头干脆 |

> 这些差异必须**在每一镜的 prompt 里都被强调**，不是只在角色档案里写一次。

## 一、剧作工程

### 1. Logline（一句话故事）

> 杜隆塔尔的同一日黎明到夜晚，一名兽人苦工与一名兽人战士，在两条战线上做着同一件事——为部落流汗、流血。当他们在篝火旁相遇，"For the Horde"这句话才第一次被还给真正配得上它的人。

### 2. 主题陈述（Theme Statement）

> **真正的部落，不是英雄一个人的史诗，而是无数无名者用同一种疲惫共同写下的一行字。**

主题不通过台词说出，**通过双线主题呼应剪辑**让观众自己得出结论——
不是因为构图相似，而是因为**情绪击点同步**。

### 3. 戏剧问题（Dramatic Question）

> "For the Horde" 这句口号，到底属于谁？

短片用 60 秒回答：**属于格罗什，也属于洛卡，属于所有流汗流血的人。**

### 4. 情感曲线

```
情绪强度
   ↑
10 |                                            ★ 篝火对视
 9 |                                          ★
 8 |                  ★ 出征 + 林场             ★
 7 |               ★         ★ 雷霆萨尔
 6 |            ★ 镜像砍击             ★ 黄昏剪影
 5 |         ★                       ★
 4 |     ★ 集结                    ★
 3 |  ★ 黎明
 2 |★
 1 |________________________________________
   0   10   20   30   40   50   60   秒
   |   一幕   |    二幕    |  三幕  |
   | 0–15s  |   15–48s   | 48–60s |
```

## 二、三幕结构

### 第一幕（0–15 秒）· 黎明 · 出工

**功能**：建立世界、建立两个角色、建立"双线平行"的视觉语法

| 镜头 | 戏剧任务 |
|------|---------|
| #1 黎明全景 | 建立时间、地点、史诗感 |
| #2 号角 | 唤醒——叙事开关被按下 |
| #3 苦工领斧 | 建立 A 线主角及阵营 |
| #4 战士佩刀 | 建立 B 线主角及阵营 |
| #5 双手特写镜像 | **第一次确立"双线呼应"语法**——观众潜意识接受"两条独立人生在向同一种疲惫汇流" |

**末尾情绪**：宁静中蕴含张力，号角余音未散

### 第二幕（15–48 秒）· 双线劳作 / 厮杀

**功能**：把"日常"和"战场"做到极致，让双线主题呼应产生压倒性的情感重量

#### 第二幕 - 上半场（15–30 秒）：力量爆发

| 镜头 | 戏剧任务 |
|------|---------|
| #6 出征大场面 | **CG 高潮 1**——千军万马，史诗感拉满 |
| #7 林场大场面 | **CG 高潮 2**——苦工劳作的史诗感（与 #6 等量） |
| #8 镜像砍击 | **主题呼应高潮**——劳动的暴力 vs 战斗的暴力，殊途同归 |
| #9 战士受伤 | 引入"代价"——英雄不是无敌的 |
| #10 苦工受伤 | 呼应——苦工流的也是血（同一种），但姿态完全不同 |

#### 第二幕 - 下半场（30–48 秒）：意志坚持

| 镜头 | 戏剧任务 |
|------|---------|
| #11 雷霆萨尔 | **戏剧高点**——魔兽迷彩蛋 + 暗示天意 |
| #12 苦工抬头看雷雨 | 跨线呼应——他与战场之间有了"无形连接" |
| #13 苦工扛金箱 | 沉重前行——意志主题 |
| #14 战士背伤兵 | 呼应——同样的沉重前行，但角度与节奏各异 |

**末尾情绪**：极度疲惫但都没倒下

### 第三幕（48–60 秒）· 黄昏 / 篝火 · 收束

**功能**：让 12 秒承载整片的情感重量

| 镜头 | 戏剧任务 |
|------|---------|
| #15 战士黄昏剪影 | 视觉静止——情绪开始沉淀（站姿，军人式拄武器） |
| #16 苦工黄昏剪影 | 情绪收束——同一片夕阳下的另一种疲惫（坐姿，劳动者式撑膝） |
| #17 篝火递肉干 | **情感最高点**——两条线终于在物理空间相遇 |
| #18 双人特写台词 | **主题揭示**——"Work, work" / "For the Horde" |
| 黑屏字幕 | **主题落地**——For those who built it |

## 三、完整分镜剧本

### 格式说明

每个镜头包含：
- **景别 / 焦段**
- **运镜**
- **画面描述**
- **声音**（对白 / 音效 / 音乐）
- **时长 / 起止时间码**
- **情绪关键词**

---

### 镜头 #1 · 黎明全景

| 项 | 内容 |
|---|---|
| 景别 | 极远景 |
| 焦段 | 24mm 广角 |
| 运镜 | **慢推**（2 秒内从 100% 推到 90%） |
| 时长 | 0:00 – 0:03（3 秒） |
| 情绪 | 史诗、宁静、蓄势 |

**画面**：
杜隆塔尔黎明。镜头从极高处俯瞰红土荒原，一道地平线，一轮血色朝阳贴着地平线升起。前景是巨大的部落狼头黑红旗在风中猎猎，旗杆木质粗糙带裂纹。营地黑色毡帐零星分布，晨雾贴地流动。远处奥格瑞玛城墙剪影。

**声音**：
- 远号角声（低、长、苍凉）
- 风声（中等强度）
- BGM：**蒙古喉音 + 单一鼓点**起拍

### 镜头 #2 · 号角手

| 项 | 内容 |
|---|---|
| 景别 | 中景 |
| 焦段 | 35mm |
| 运镜 | 固定（仰角约 15°） |
| 时长 | 0:03 – 0:05（2 秒） |
| 情绪 | 唤醒、肃穆 |

**画面**：
号角塔顶端，一名中年女兽人号角手鼓腮吹号。她戴狼牙项链，皮肤深绿，呼出的白雾在朝阳逆光中散开。镜头微微仰角，号角金属雕花清晰可见。背景是逐渐亮起的天空，云层被阳光镶上金边。

**声音**：
- 号角长鸣（升至最高音）
- 喉音 BGM 加入弦乐铺底

### 镜头 #3 · A 线 · 苦工领斧（跟拍）

| 项 | 内容 |
|---|---|
| 景别 | 跟拍中景 |
| 焦段 | 35mm |
| 运镜 | **Steadicam 跟拍**（侧后方跟随） |
| 时长 | 0:05 – 0:08（3 秒） |
| 情绪 | 日常、机械、沉默 |

**画面**：
苦工大队从营地军械库领取劈柴斧，一字队列。**主角格罗什**走在队列中段（左眉疤、独辫、赤脚），他面无表情接过斧头，掂了掂分量，扛上左肩。其他苦工动作几乎一致。脚下扬起红土。镜头与他保持 2 米距离侧后方跟随。

**声音**：
- 金属交接声（哐当哐当）
- 苦工低声："Yes？"（魔兽原版语音，疲惫版）
- 集体脚步声
- BGM 加入低音提琴

**字幕**：（无）

### 镜头 #4 · B 线 · 战士佩刀（跟拍）

| 项 | 内容 |
|---|---|
| 景别 | 跟拍中近景（比 #3 苦工更紧的景别——突出战士的紧绷神态） |
| 焦段 | 35mm |
| 运镜 | **Steadicam 跟拍**（与 #3 节奏呼应，但角度反向——侧前方跟随，速度更快、有爆发力） |
| 时长 | 0:08 – 0:11（3 秒） |
| 情绪 | 整肃、即将爆发 |

**画面**：
战士小队从同一个军械库领取双手战斧，列队整齐如石墙，铁靴整齐踏地如鼓点。**主角洛卡**（35 岁，2.30m 挺立，深翡翠绿皮肤，右脸纹身，顶髻高束）走在队列前段，他单手接过一把刃口有 4 个缺口的战斧，**手腕一抡空斧花展示控制力**——这是战士的肌肉记忆，与苦工的"机械接斧"形成强烈节奏反差。腰间布袋微微鼓起（暗示肉干）。背景能看到小队中其他战士各异的脸——有人擦剑、有人系皮带、有人在咬牙——一群真实的兽人战士，不是流水线复制。

**声音**：
- 重型铁器碰撞（更沉）
- 整齐铁靴踏地
- 战鼓声轻轻加入
- BGM 加入男声合唱低音

**导演笔记**：
> #3 与 #4 不要做"同一动作的复制"。
> 苦工是"接、掂、扛"——三个动作里全是疲惫；
> 战士是"接、抡、扛"——三个动作里全是控制。
> **同样是领取武器，但身体语言来自完全不同的人生。**

### 镜头 #5 · 双线特写 · 双手握紧（核心呼应镜）

| 项 | 内容 |
|---|---|
| 景别 | 极近特写（双手） |
| 焦段 | 85mm 微距 |
| 运镜 | **构图刻意区分**——5A 俯拍木柄缠破布的细节；5B 侧拍皮革柄的铆钉与干血迹 |
| 时长 | 0:11 – 0:13（2 秒） |
| 情绪 | 宣告主题 |

**画面**：

**前 1 秒（5A · 苦工）**：
**俯拍角度**，从苦工肩上向下看他的双手——格罗什 42 岁布满老茧的手粗糙发干，指甲缝嵌满黑泥与红土，正缓缓握紧劈柴斧的木柄。木柄上缠着褪色发黄的破布，被汗水反复浸出盐渍。无名指有一道劳动划伤的旧疤。

**后 1 秒（5B · 战士）**：
**侧拍 90 度角**，从战士右侧看他的双手——洛卡 35 岁更年轻紧实的手抹了一把脸上的汗与血，然后握紧战斧的皮革缠柄。皮革上有 4 枚锻铁铆钉，柄身沾染干涸暗血迹（不是新血，是旧战的痕迹）。虎口有一道战斗造成的斜疤。

**两个画面的核心差异**：
- 视角不同（俯拍 vs 侧拍）
- 手的姿态不同（缓缓收紧 vs 抹完汗才握）
- 武器细节不同（破布木柄 vs 铆钉皮革柄）
- 疤痕不同（劳动旧疤 vs 战斗斜疤）

**唯一相同的**：
两双手都因为用力而**指节发白、青筋隆起**——这是全片**唯一刻意做对位的视觉细节**，也是主题呼应的"锚点"。

**声音**：
- 5A：木柄破布吱呀声 + 苦工沉重呼吸
- 5B：皮革握紧声 + 战士急促呼吸
- BGM：鼓点开始变密

**导演笔记**：
> 这是全片"双线呼应语法"的**官方宣告镜头**。
> 观众的潜意识从这一刻开始接受："**这是两个不同的人，他们的人生不一样，但都用力地活着。**"
> 不要做成"两张构图相同的双胞胎手"。两张图叠在一起应该有 60% 的差异。

### 镜头 #6 · B 线 · 部落出征大场面

| 项 | 内容 |
|---|---|
| 景别 | 极远景 → 鸟瞰 |
| 焦段 | 24mm 广角 |
| 运镜 | **升降机大幅运动**：从地面战士冲锋的视角，跟随 1 秒后**陡然升起**至俯瞰 3 秒 |
| 时长 | 0:13 – 0:17（4 秒） |
| 情绪 | 史诗爆发、压倒性 |

**画面**：
镜头起在地面，跟拍一名狼骑兵从奥格瑞玛大门冲出。运镜陡然向上飞升，画面拉开——千军万马的部落大军从大门蜂拥而出，狼骑兵、巨魔战士、双足飞龙编队、巨型攻城车，红土被踏起漫天烟尘，黑红旗帜如海浪。地平线上是燃烧军团旗号或人族联军的远影。

**导演笔记**：
> 直接对标《魔戒》洛汗骑兵冲锋助洛拉斯解围的镜头。
> 这是 **CG 高潮 1**，必须做到 1080p 看不到任何 AI 瑕疵。
> Seedance 2.0 抽卡预算可以单镜砸到 30 次。

**声音**：
- 战吼震天（千人合声）
- 战鼓密集
- 狼嚎、马蹄、金属磕碰
- BGM 进入**主题段 A · 雄壮出征**

### 镜头 #7 · A 线 · 林场大场面

| 项 | 内容 |
|---|---|
| 景别 | 鸟瞰俯拍 |
| 焦段 | 35mm（高空） |
| 运镜 | **固定俯拍 → 缓慢推近** |
| 时长 | 0:17 – 0:21（4 秒） |
| 情绪 | 史诗劳作、震撼 |

**画面**：
高空俯拍杜隆塔尔大林场。上百名兽人苦工同时挥斧，红木林被开出宽阔伐区，金矿坑像一个巨大的伤口嵌在地面，木支架像蜘蛛网。烟尘和木屑在金黄光柱中漂浮。镜头缓慢推近一个工区，可以看到苦工们整齐如鼓点的劳作节奏——**视觉节奏与 #6 出征大军完全同步**。

**导演笔记**：
> 这是 **CG 高潮 2**——而且是**全片最重要的视觉论点**：
> "苦工的劳作和战士的冲锋，在体量、节奏、史诗感上是平等的"
> 这一镜如果做不到与 #6 等量级，整部片的立意就垮了。
> 必须出图、出视频时和 #6 反复对照，**两镜可以叠化都不违和**。

**声音**：
- 千斧齐落（如同战吼）
- 劳动号子（兽人沙哑低吼，类似纤夫号子）
- 金石撞击声
- BGM 持续主题段 A，但鼓点变成**劳作节奏**

### 镜头 #8 · 双线砍击（核心主题镜）

| 项 | 内容 |
|---|---|
| 景别 | 极近特写 |
| 焦段 | 85mm 微距 |
| 运镜 | 8A 仰角微距（看斧从上方落下）／ 8B 平拍微距（看斧从横向劈开）—— **两个角度刻意不同** |
| 时长 | 0:21 – 0:24（3 秒，分 8A + 8B 各 1.5 秒） |
| 情绪 | 主题揭示、暴力诗意 |

**画面**：

**8A（0:21 – 0:22.5）· 仰角微距**：
镜头从树干根部仰视——格罗什的劈柴斧从画面**上方坠下**劈进红木树干的瞬间。木屑炸裂**向上、向四周**飞溅，逆光金黄丁达尔光柱穿透。汗珠从他眉骨疤痕旁滑落，飞向镜头。**重心向下**的运动感。

**8B（0:22.5 – 0:24）· 平拍微距**：
镜头从战场齐胸高度平拍——洛卡的战斧从画面**右侧横向劈过**，切入人族士兵护甲的瞬间。血雾**向左、向远**喷散，冷青烟尘飘动。汗珠从他纹身脸颊滑落，飞向镜头。**重心向前**的运动感。

**两镜的关键差异**：
- 角度：8A 仰拍 / 8B 平拍
- 运动方向：8A 上→下 / 8B 右→左
- 飞溅物：8A 木屑（向上） / 8B 血雾（向远）
- 光线：8A 暖金丁达尔 / 8B 冷青烟尘
- 重心：8A 下沉 / 8B 前推

**两镜的共振点**：
- 慢动作速率近似（约 120fps）
- 镜头时长相同（1.5s）
- 汗珠都从主角面部飞向镜头（情绪锚点）
- 音桥同帧切换（劈砍木声 → 金属撕裂声）

**声音**：
- 8A：劈砍木声（清脆爆裂）
- 8B：金属穿透甲胄声（沉闷撕裂）
- **音桥**：8A 的劈砍声末尾**直接切到 8B 的撕裂声**——听觉上是一个动作的两个回声
- BGM 鼓点重击

**导演笔记**：
> **这是全片在导演层面最核心的一镜**。
> 视觉上故意**一上一下、一木一血、一金一青**，强化生 vs 死的对位张力。
> 但音桥**必须**在同一帧切换——视觉做差异，听觉做共振。
> 这就是真正的电影 CG 语法。

### 镜头 #16 · A 线 · 苦工黄昏剪影（呼应 #15）★ 海报候选

**画面**：
林场出口的红土小径旁，格罗什把金箱放在地上，**整个人坐在一根新伐倒的原木上**。
他不会像战士那样军姿拄武器站着——他选择了 42 岁劳动者最熟悉的休息姿态：
**双肘撑在膝盖上、上身前倾、独辫垂在身前、肩膀微塌**。
背对镜头，望向同一片地平线橙红夕阳。

- **节奏**：守望 vs 歇息

- 风声（与 #15 同样的强度和频率）
- 远处千斧齐落渐弱
- BGM 苍凉段持续

**导演笔记**：
> #15 和 #16 是全片的**电影海报候选镜**——但请绝对避免做成"两张构图重合的双胞胎图"。
>
> 战士站着、拄战斧——这是**军人的姿态**，他每一刻都在准备战斗。
> 苦工坐着、撑膝盖——这是**劳动者的姿态**，他知道明天还要扛箱子，所以现在能坐就坐。
>
> **同一片夕阳下，两种不同的休息**——这才是真正的电影感。
> 观众到这里应该明白："他们走的是不同的路，但都很累。"
> 不是"他们是同一个人"，而是"他们是两种不同的人，被同一个时代压着同一种疲惫"。
