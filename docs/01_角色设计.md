# 01 · 角色设计

> 本片只有 **2 个核心角色** + **3 个功能性配角**。
> 越简单的角色阵容越能撑起 60 秒的情感重量。

---

## 一、角色阵容速览

| 出场顺序 | 角色 | 阵营 | 职能 | 戏份 |
|---|---|---|---|---|
| 主角 A | **格罗什 (Grosh)** | 部落 · 苦工 | 后方劳作线主角 | ~25 秒 |
| 主角 B | **洛卡 (Lok'ra)** | 部落 · 战士 | 前线厮杀线主角 | ~25 秒 |

| 配角 2 | 新晋苦工 | 部落 | 镜像组对照 | ~3 秒 |
| 配角 3 | 战士同伴（昏迷） | 部落 | 情绪推力 | ~2 秒 |
| 暗示 | 萨尔（剪影） | 部落酋长 | 雷霆镜（#11）背景暗示 | ~1 秒 |

## 二、主角 A：格罗什 / Grosh

> "他不是英雄。他只是部落最早醒来、最晚睡的那个人。"

### 1. 角色档案

| 项目 | 设定 |
|------|------|
| 全名 | Grosh of the Frostwolf（霜狼氏族的格罗什） |
| 年龄 | 兽人 42 岁（对应人类 50 岁，壮年偏老） |
| 身高 | 2.05 m（兽人偏矮，长期负重略弓背） |
| 阵营 | 部落 · 杜隆塔尔苦工大队 |
| 出身 | 第二次大战期间出生于人族战俘营，母亲死于屠杀，父亲是萨尔解放战俘营时救出的老兵 |
| 职业 | 苦工（Peon）—— 伐木、采金、搬运、修建 |

### 2. 性格 / 心理

- **沉默而坚韧**——一天说不超过 5 个词，但每个词都用力
- 对部落有一种朴素信念：**"我们做的每一件小事，是为了部落明天还在"**
- 不羡慕英雄，但偷偷敬仰萨尔
- 心里有疙瘩：**觉得自己"配不上"For the Horde 这句口号**——这是全片的情感伏笔，结局解开

### 3. 心理弧光（戏剧任务）

| 阶段 | 状态 | 触发点 |
|------|------|--------|
| 开场 | 机械重复，麻木 | 黎明号角 |
| 中段 | 抬头看见萨尔雷霆，第一次有"参与感" | 镜头 #11–12 |
| 高潮 | 与战士对视，意识到"我们是同一个人" | 镜头 #17 |
| 结局 | 笑出来，第一次主动说出"Work, work" | 镜头 #18 |

### 4. 外形细节（这部分务必抄进 Prompt）

```
Orc peon, age 42, height 2.05m, slightly hunched from years of labor.
Olive-green skin tanned by sun, smeared with red Durotar dust.
Short flat tusks (worn down, not aggressive).
Scar across LEFT eyebrow (whip mark from human captivity, childhood).
Frostwolf clan tattoo on RIGHT shoulder (faded blue ink, wolf head).
Salt-and-pepper black hair pulled into single thick braid down back.
Deep crow's feet, weary eyes the color of old amber.
Calloused hands, fingernails black with soil.
```

### 5. 服装 / 道具

| 部位 | 服装 | 备注 |
|------|------|------|
| 上身 | 粗麻无袖短褂，左肩有补丁 | 灰褐色 |
| 下身 | 破布腰围 + 兽皮短裙 | 杜隆塔尔标准 |
| 腰部 | 铁皮宽腰带（变形），系一只木水葫芦 | 葫芦边缘有牙印 |
| 手 | 牛皮护腕（左手破洞） | |
| 脚 | **赤脚**（苦工标配） | 脚底厚茧、缠麻布 |
| 武器 | 钝口劈柴斧，木柄缠破布 | **不是战斧**——这是关键差异，不要画成战斗武器 |

### 6. Midjourney 一致性 Prompt（cref 锚定图）

```
Character sheet of an orc peon worker, age 42, height 2.05m,
olive-green sun-burned skin, smeared with red dust,
short worn-down tusks, scar across left eyebrow,
faded Frostwolf clan wolf-head tattoo on right shoulder,
single thick braid of salt-and-pepper black hair,
weary amber eyes with deep crow's feet,
wearing rough linen sleeveless tunic with patch on left shoulder,
leather belt with wooden gourd canteen, bare feet wrapped in linen,
holding a worn lumber axe with rag-wrapped wooden handle,
neutral standing pose, three-quarter view,
front and side reference, Warcraft 2016 movie style,
hyperdetailed, 8K, cinematic lighting, white background
--ar 16:9 --style raw --v 7
```

> 出图后挑一张做 `--cref` 锚定，全片所有镜头都用同一张参考图。

## 三、主角 B：洛卡 / Lok'ra

> "他不是萨尔，但他是萨尔身后第十排第三个人。"

### 1. 角色档案

| 项目 | 设定 |
|------|------|
| 全名 | Lok'ra of Durotar（杜隆塔尔之子洛卡） |
| 年龄 | 兽人 35 岁（对应人类 30 岁，巅峰战力） |
| 身高 | 2.30 m（兽人战士标准偏高） |
| 阵营 | 部落 · 杜隆塔尔正规军 |
| 出身 | 杜隆塔尔出生的**第一代自由兽人**，没坐过人族牢，从小是萨尔的学员 |
| 职业 | 步兵小队长 |

### 2. 性格 / 心理

- **直白、骁勇、话少但有重量**
- 不像奥格瑞姆 / 卡尔加那种贵族派——**他对苦工有真实的尊重**，因为他爹就是苦工
- 战场上是杀器，营地里是社牛
- 腰间布袋里永远装 3 块母亲做的风干肉干——最后一块给了苦工

### 3. 心理弧光

| 阶段 | 状态 | 触发点 |
|------|------|--------|
| 开场 | 战意昂扬 | 黎明号角 |
| 中段 | 重伤，咬牙撑着 | 镜头 #9 |
| 高潮 | 黄昏归营，发现一个苦工和自己一样疲惫 | 镜头 #16 |
| 结局 | 把最后一块肉干递出去 | 镜头 #17 |

### 4. 外形细节

```
Orc warrior, age 35, height 2.30m, muscular but lean (battle-honed, not gym-built).
Deep emerald-green skin with several old scars.
Long curved tusks, chipped at the right tip.
Horizontal long scar across chest (from Barrens campaign, visible above armor).
Tribal black ink tattoo covering RIGHT side of face (cheek to jawline).
Black hair shaved on sides, top tied into warrior's topknot.
Eyes pale yellow like wolf, intense but tired.
Strong jaw, dirt and dried blood on face.
```

### 5. 服装 / 道具

| 部位 | 服装 | 备注 |
|------|------|------|
| 头 | 无头盔（黄昏归营时摘掉了） | 战斗段可加铁面甲 |
| 上身 | **磨损的黑铁板甲**，胸甲多处凹陷 | **不要闪亮** —— 这是重点 |
| 肩 | 灰狼皮披肩 | 战斗中沾血 |
| 腰 | 皮质战裙 + 铁腰带 + **小布袋** | 布袋里装 3 块肉干（关键道具） |
| 腿 | 皮护胫 + 铁靴 | 靴口卷边 |
| 武器 | 双手钢制战斧，刀刃 4 个缺口 | War3 部落士兵标准款 |

### 6. Midjourney 一致性 Prompt

```

deep emerald-green skin, lean muscular battle-honed build,
long curved tusks chipped at right tip,

--ar 16:9 --style raw --v 7
```

## 四、配角设定

### 1. 营地号角手（#2 出场，2 秒）

- 中年女兽人，皮肤更深绿，戴狼牙项链
- 站在号角塔上鼓腮吹号，呼出白雾
- 不需要 cref，一次性角色

### 2. 新晋苦工（可选 #3 出场）

- 年轻男兽人，刚被"召唤生产"，眼神还干净
- 排队时站在格罗什身后
- **建议保留**，因为最后镜头格罗什带他走出营地形成轮回（如果加进去）

> 备注：当前剧本没硬性安排，留作可选元素。

### 3. 战士同伴（#14 出场，2 秒）

- 中年男兽人战士，被洛卡背在背上，半昏迷
- 头部血迹、左臂耷拉、还活着
- 设定上他不死（保持基调不悲情）

### 4. 萨尔（#11 暗示，1 秒）

- **不出正脸**——只在闪电劈下的瞬间，远景剪影站在战场高坡
- 标志：双手举起雷电之锤、风衣随风（剪影即可识别）
- 这是一个**彩蛋**，给资深魔兽迷的福利

## 五、角色一致性工作流（重要）

> AI 短片最大的死亡点：**角色每个镜头长得不一样**。
> 必须在出图前先打通这一关。

### 步骤

1. **出 cref 锚定图**（用上面的 Prompt 出 4–6 张，挑最好的 1 张）
2. **格罗什 + 洛卡 各 1 张定版图**，保存到 `/assets/characters/`
3. 之后所有镜头 Prompt 末尾加 `--cref [图链接] --cw 100`
4. 重要细节（疤、纹身、武器缺口）**每次都在 prompt 里复述一遍**（cref 不保证细节稳定）

### 常见翻车点

| 翻车 | 解法 |
|------|------|
| 苦工一会有獠牙一会没有 | Prompt 里强制 `short worn tusks visible` |
| 战士的胸甲一会闪一会不闪 | 强制 `battle-worn matte iron, NOT shiny` |
| 苦工变战士（拿了战斧） | Prompt 强调 `lumber axe with rag-wrapped handle, NOT war axe` |
| 萨尔露脸（穿帮） | Prompt 强制 `silhouette only, backlit, no face visible` |

## 六、检查清单（出图前对照）

- [ ] 格罗什：左眉疤、右肩狼头纹身、独辫、赤脚、劈柴斧（非战斧）
- [ ] 洛卡：右脸纹身、胸口横疤、缺口战斧、磨损板甲（非闪亮）
- [ ] 两人都是兽人**典型獠牙**，不是兽人战士网游 Q 版风格
- [ ] 服装色调：格罗什土褐 / 洛卡深铁 + 狼灰
- [ ] **绝对不要**：金光闪闪的盔甲、卡通五官、欧美超英肌肉模板
