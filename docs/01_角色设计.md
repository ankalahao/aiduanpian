# 01 · 角色设计

> 本片只有 **2 个核心角色** + **3 个功能性配角**。
> 越简单的角色阵容越能撑起 60 秒的情感重量。

---

| 出场顺序 | 角色 | 阵营 | 职能 | 戏份 |

## 二、主角 A：格罗什 / Grosh

> "他不是英雄。他只是部落最早醒来、最晚睡的那个人。"

### 1. 角色档案

| 项目 | 设定 |
|------|------|
| 全名 | Grosh of the Frostwolf（霜狼氏族的格罗什） |
| 年龄 | 兽人 42 岁（对应人类 50 岁，壮年偏老） |
| 身高 | 2.05 m（兽人偏矮，长期负重略弓背） |
| 阵营 | 部落 · 杜隆塔尔苦工大队 |
| 出身 | 第二次大战期间出生于人族战俘营，母亲死于屠杀，父亲是萨尔解放战俘营时救出的老兵 |
| 职业 | 苦工（Peon）—— 伐木、采金、搬运、修建 |

### 2. 性格 / 心理

- **沉默而坚韧**——一天说不超过 5 个词，但每个词都用力
- 对部落有一种朴素信念：**"我们做的每一件小事，是为了部落明天还在"**
- 不羡慕英雄，但偷偷敬仰萨尔
- 心里有疙瘩：**觉得自己"配不上"For the Horde 这句口号**——这是全片的情感伏笔，结局解开

### 3. 心理弧光（戏剧任务）

| 阶段 | 状态 | 触发点 |
|------|------|--------|
| 开场 | 机械重复，麻木 | 黎明号角 |
| 中段 | 抬头看见萨尔雷霆，第一次有"参与感" | 镜头 #11–12 |
| 高潮 | 与战士对视，意识到"我们是同一个人" | 镜头 #17 |
| 结局 | 笑出来，第一次主动说出"Work, work" | 镜头 #18 |

### 4. 外形细节（这部分务必抄进 Prompt）

```
Orc peon, age 42, height 2.05m, slightly hunched from years of labor.
Olive-green skin tanned by sun, smeared with red Durotar dust.
Short flat tusks (worn down, not aggressive).
Scar across LEFT eyebrow (whip mark from human captivity, childhood).
Frostwolf clan tattoo on RIGHT shoulder (faded blue ink, wolf head).
Salt-and-pepper black hair pulled into single thick braid down back.
Deep crow's feet, weary eyes the color of old amber.
Calloused hands, fingernails black with soil.
```

| 部位 | 服装 | 备注 |

| 上身 | 粗麻无袖短褂，左肩有补丁 | 灰褐色 |
| 下身 | 破布腰围 + 兽皮短裙 | 杜隆塔尔标准 |
| 腰部 | 铁皮宽腰带（变形），系一只木水葫芦 | 葫芦边缘有牙印 |
| 手 | 牛皮护腕（左手破洞） | |
| 脚 | **赤脚**（苦工标配） | 脚底厚茧、缠麻布 |
| 武器 | 钝口劈柴斧，木柄缠破布 | **不是战斧**——这是关键差异，不要画成战斗武器 |

## 三、主角 B：洛卡 / Lok'ra

> "他不是萨尔，但他是萨尔身后第十排第三个人。"

### 1. 角色档案

| 项目 | 设定 |
|------|------|
| 全名 | Lok'ra of Durotar（杜隆塔尔之子洛卡） |
| 年龄 | 兽人 35 岁（对应人类 30 岁，巅峰战力） |
| 身高 | 2.30 m（兽人战士标准偏高） |
| 阵营 | 部落 · 杜隆塔尔正规军 |
| 出身 | 杜隆塔尔出生的**第一代自由兽人**，没坐过人族牢，从小是萨尔的学员 |
| 职业 | 步兵小队长 |

### 2. 性格 / 心理

- **直白、骁勇、话少但有重量**
- 不像奥格瑞姆 / 卡尔加那种贵族派——**他对苦工有真实的尊重**，因为他爹就是苦工
- 战场上是杀器，营地里是社牛
- 腰间布袋里永远装 3 块母亲做的风干肉干——最后一块给了苦工

### 3. 心理弧光

| 阶段 | 状态 | 触发点 |
|------|------|--------|
| 开场 | 战意昂扬 | 黎明号角 |
| 中段 | 重伤，咬牙撑着 | 镜头 #9 |
| 高潮 | 黄昏归营，发现一个苦工和自己一样疲惫 | 镜头 #16 |
| 结局 | 把最后一块肉干递出去 | 镜头 #17 |

### 4. 外形细节

```
Orc warrior, age 35, height 2.30m, muscular but lean (battle-honed, not gym-built).
Deep emerald-green skin with several old scars.
Long curved tusks, chipped at the right tip.
Horizontal long scar across chest (from Barrens campaign, visible above armor).
Tribal black ink tattoo covering RIGHT side of face (cheek to jawline).
Black hair shaved on sides, top tied into warrior's topknot.
Eyes pale yellow like wolf, intense but tired.
Strong jaw, dirt and dried blood on face.
```

## 四、配角设定

- 站在号角塔上鼓腮吹号，呼出白雾

### 2. 新晋苦工（可选 #3 出场）

- 年轻男兽人，刚被"召唤生产"，眼神还干净
- 排队时站在格罗什身后
- **建议保留**，因为最后镜头格罗什带他走出营地形成轮回（如果加进去）

### 3. 战士同伴（#14 出场，2 秒）

- 中年男兽人战士，被洛卡背在背上，半昏迷
- 头部血迹、左臂耷拉、还活着
- 设定上他不死（保持基调不悲情）

### 4. 萨尔（#11 暗示，1 秒）

- **不出正脸**——只在闪电劈下的瞬间，远景剪影站在战场高坡
- 标志：双手举起雷电之锤、风衣随风（剪影即可识别）
- 这是一个**彩蛋**，给资深魔兽迷的福利

## 五、角色一致性工作流（Seedream 2.0 流程，重要）

> AI 短片最大的死亡点：**角色每个镜头长得不一样**。
> Seedream 2.0 用 **Image Reference**（图像参考）替代 Midjourney 的 `--cref`，
> 一致性效果实测好于 Midjourney v7。

### 标准三步流程

#### Step 1：出主锚定图（Day 2）

用本文档第 2、3 节给出的两段 **Seedream 2.0 角色锚定图 Prompt**，
分别为格罗什、洛卡各出 6–8 张候选（每张约 ¥0.4，单角色成本 ¥3 内）。

**挑选标准**：
- 兽人解剖正确（獠牙朝向、眉骨、下颌、绿皮色调）
- 比例与剧本一致（格罗什 2.05m 略弓背 / 洛卡 2.30m 挺立）
- 服装道具关键特征齐全
- **真实 PBR 质感**——皮肤有毛孔、不塑料、不油画

挑选后保存为：

```
assets/characters/
├── grosh_ref_v1.png      ← 格罗什主锚定图（必备）
├── grosh_ref_face.png    ← 格罗什面部特写（备用）
├── lokra_ref_v1.png      ← 洛卡主锚定图（必备）
└── lokra_ref_face.png    ← 洛卡面部特写（备用）
```

#### Step 2：所有镜头出图都挂图像参考（Day 3–4）

在 Seedream 2.0 UI 里：
1. **新建生成任务**
2. 在 **"参考图 / Image Reference"** 区域上传锚定图
3. **参考强度（reference_strength）**：建议 **0.7**
   - 太高（>0.85）：画面被锚定图构图绑架，无法生成新场景
   - 太低（<0.5）：角色脸长得不像
4. Prompt 中**仍然要复述关键细节**（疤痕、纹身、武器特征）——
   Seedream 的 Image Reference 主要锁面部 / 五官，配饰细节不一定保真

#### Step 3：Seedance 2.0 视频生成时挂首帧（Day 5–7）

Seedance 2.0 视频生成支持**首帧锁定**：
- 把 Step 2 出的关键帧上传为 **首帧参考图**
- Seedance 会从该帧开始动画，确保视频起点角色与关键帧一致
- 这一步几乎可以**消除"视频里角色变脸"**这一最大死角

### 常见翻车与解法

| 翻车 | 解法 |
|------|------|
| 苦工一会有獠牙一会没有 | Prompt 里强制 `short worn lower tusks visible (mandatory)` |
| 战士的胸甲一会闪一会哑 | 强制 `battle-worn matte iron plate armor with dents, NOT shiny, NOT polished` |
| 苦工拿成战斧（武器混淆） | 强制 `worn lumber axe with rag-wrapped wooden handle, NOT war axe, NOT battle axe` |
| 兽人脸变成"绿皮人类" | 强制 `long jutting lower jaw, prominent lower tusks growing upward, thick brow ridge, broad flat nose` |
| 萨尔露脸（彩蛋穿帮） | 强制 `silhouette only, backlit, full black shape, no facial details visible at all` |
| 出图变油画感 | 强制 `Photorealistic CGI, NOT painterly, NOT oil painting, NOT Blizzard stylized` |
| 皮肤塑料感 | 强制 `visible skin pores, subsurface scattering, micro-wrinkles, sweat sheen` |

### 一致性验收标准

每个镜头出图后，逐项对照：

- [ ] 把镜头关键帧人物面部裁切出来，与锚定图面部 50% 透明度叠加
- [ ] **五官位置重合度 ≥ 80%**（鼻子、嘴角、眉骨、獠牙位置）
- [ ] 关键标识齐全：左眉疤 / 右肩纹身（格罗什）；右脸纹身 / 胸口横疤（洛卡）
- [ ] 武器特征齐全：劈柴斧木柄破布 / 战斧 4 处缺口
- [ ] PBR 质感达标：肤色有层次、毛孔可见、汗光自然

## 六、检查清单（出图前对照）

- [ ] 格罗什：左眉疤、右肩狼头纹身、独辫、赤脚、劈柴斧（非战斧）
- [ ] 洛卡：右脸纹身、胸口横疤、缺口战斧、磨损板甲（非闪亮）

- [ ] 服装色调：格罗什土褐 / 洛卡深铁 + 狼灰
- [ ] **绝对不要**：金光闪闪的盔甲、卡通五官、欧美超英肌肉模板
