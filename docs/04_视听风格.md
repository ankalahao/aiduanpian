> 风格是把"剧本想说的话"翻译成"观众眼睛和耳朵接收的语言"。

## 二、摄影语言

### 1. 焦段分配

| 焦段 | 用途 | 出现镜头 |
|------|------|---------|
| 24mm 广角 | 大场面、史诗远景 | #1, #6 |
| 35mm 标头 | 中近景叙事、跟拍 | #2, #3, #4, #7, #13, #14 |
| 50mm 中焦 | 中景情感戏 | #9, #10, #12, #17 |
| 85mm 长焦 | 特写、剪影 | #5, #8, #11, #15, #16, #18 |

### 2. 运镜规范

| 镜头 | 运镜 | 备注 |
|------|------|------|
| 史诗大场面 (#6, #7) | 升降机大幅运动 | Veo 3 用 "drone shot rising up" 关键词 |
| 跟拍 (#3, #4, #13, #14) | Steadicam 平稳 | Veo 3 用 "steady tracking shot" |
| 受伤镜 (#9, #10) | 微微手持晃动 | Veo 3 用 "subtle handheld shake" |
| 剪影 (#15, #16) | 完全固定 | Veo 3 用 "locked-off static shot" |
| 篝火戏 (#17) | 慢推 + 越肩切换 | 分两段抽卡再剪辑 |

### 3. 镜头语法的"四个不"

1. **不晃动**：除受伤镜外，全部稳定运镜
2. **不旋转**：旋转镜头廉价感强，禁用
3. **不广角畸变**：人脸特写永远 50–85mm，绝对不用 24mm 拍人脸
4. **不快切**：每个镜头给观众至少 2 秒看清

### 4. 构图原则

- **三分法 + 中央对称**双轨制
- 大场面用三分法（地平线在 1/3 处）
- 双线镜像必须**严格中央对称**——这是镜像剪辑的视觉基础
- 黄昏剪影用**底部 1/4 地平线** + **中央人物剪影**（参考最后的武士海报构图）

## 三、调色方案

### 1. 三档双色温对位法

整片用 **三档色温对位**讲故事：

```
档位 1：黎明 (S1)
A线 / B线 共用 —— Orange-Brown LUT
朝阳橙 + 雾蓝阴影
色温 3800K
情绪：宁静蓄势

档位 2：日间分裂 (S2 / S3)
A线 苦工 —— Golden Hour LUT
蜂蜜金 + 木褐阴影
色温 5500K
情绪：温暖、劳作、生

B线 战士 —— Teal-Rust LUT
冷青 + 血锈阴影
色温 6500K
情绪：冰冷、厮杀、死

档位 3：黄昏收束 (S4 / S5)
A线 / B线 —— 双色温收敛到 Magic Hour
橙红 + 紫蓝阴影
色温 4200K（剪影）→ 1900K+7000K（篝火双补色）
情绪：合一、和解
```

### 2. 重点场景调色细则

#### S2 林场（A 线）
- **Lift**（暗部）：木褐 R+10 G+5 B-5
- **Gamma**（中间调）：蜂蜜金 R+15 G+10 B-10
- **Gain**（高光）：朝阳橙 R+20 G+5 B-15
- **饱和度**：+15
- **对比度**：+20

#### S3 战场（B 线）
- **Lift**：深青 R-15 G-5 B+10
- **Gamma**：冷灰 R-5 G-3 B+5
- **Gain**：血锈红高光（用 HSL 单独提红色）
- **饱和度**：-10（整体压低）+ 红色单独 +30
- **对比度**：+30

#### S5 篝火夜（高潮）
- **双补色 LUT**：橙 + 蓝
- 篝火主光区域单独 Power Window，色温拉到 1900K
- 背景区域单独 Power Window，色温拉到 7000K
- 中间过渡用柔和羽化

### 3. 调色工具

- **必须用 DaVinci Resolve**（剪映免费版调色不够细）
- 每场景做**节点（Node）**调色：
  - Node 1：基础校色（白平衡、曝光）
  - Node 2：LUT 风格化
  - Node 3：Power Window 局部
  - Node 4：颗粒 + 锐化

## 四、美术与道具规范

### 1. 美术风格

| 维度 | 规范 |
|------|------|
| 总体 | **油画质感**——边缘略柔，中间调厚重 |
| 表面 | 全部"用过、磨损、有故事"——禁止任何"新出厂"质感 |
| 金属 | 哑光、有划痕、有锈、有指纹 |
| 皮革 | 有汗渍、有缝补、有破洞 |
| 布料 | 起毛、有补丁、有泥土 |
| 木材 | 有裂纹、有节疤、有水渍 |

### 2. 禁用元素清单

> 这些一旦出现就毁掉史诗感：

- ❌ 金光闪闪的盔甲（这不是 WoW 网游）
- ❌ 卡通五官、Q 版面相
- ❌ 现代人脸轮廓（必须保持兽人特征：长下颌、大嘴、獠牙）
- ❌ 数字字体（除最后字幕外，画面中绝对不能出现现代字体）
- ❌ 塑料感肌肤（AI 出图最大的死角，必须 prompt 强制 `skin pores, micro-wrinkles`）

### 3. 关键道具清单（再强调）

| 道具 | 出现镜头 | 关键特征 |
|------|---------|---------|
| 部落狼头旗 | #1, #5, #15 | 黑底红边狼头、布料磨损、6 米高 |
| 苦工劈柴斧 | #3, #5, #8A, #16 | **木柄缠破布、刀刃钝、不是战斧** |
| 战士战斧 | #4, #5, #8B, #15 | **4 个缺口、皮革柄、双手斧** |
| 战士肉干袋 | #4, #17 | 小皮袋、3 块肉干（最后一块给苦工） |
| 部落金箱 | #13 | 木箱铁包角、刻部落徽记 |
| 号角 | #2 | 铜质雕花、约 1 米长 |

## 五、字体设计

### 1. 字体选择

| 用途 | 英文字体 | 中文字体 |
|------|---------|---------|
| 主标题 / 末尾字幕 | **Trajan Pro Bold**（魔兽电影标配） | **思源宋体 Heavy** |
| 副标题 | Trajan Pro Regular | 思源宋体 Bold |
| 字幕条（如需） | Cinzel | 方正字魂工厂 |

> Trajan Pro 是好莱坞史诗片字幕的"行业标准"——
> 《角斗士》《300 勇士》《指环王》《魔兽》全用它。

### 2. 字幕动画

| 文字 | 入场动画 | 时长 |
|------|---------|------|
| "For the Horde." | 逐字浮现 + 金色描边 | 1 秒 |
| "And for those who built it." | 在第一行结束后浮现 | 1 秒 |

避免用现代滑入、抖动等动画——**只用最简单的 Fade In**。

### 3. 字幕颜色

- 主文字：**纯白 #FFFFFF**
- 描边：**金色 #C9A961**（部落色调）
- 阴影：**黑色 #000000 50% 透明度**

## 七、音效设计（Sound Design）

### 1. 三层声场结构

```
环境层（Ambient Layer）—— 永远存在
└─ 风、远号角、远战吼、虫鸣、火焰背景声

动作层（Foley Layer）—— 跟随动作
└─ 脚步、铁器、皮革、布料、武器、呼吸

情绪层（Emotional Layer）—— 跟随戏剧
└─ BGM、心跳、留白、回响
```

### 3. 音桥与音画对位规范

#### 音桥（Audio Bridge）—— 主题镜头 #8

```
0:21.0 ──┬── 8A 视频开始（木屑特写）
         │   8A 音效：劈砍木声 ATTACK 0.1s
0:22.0 ──┤   8A 音效：劈砍木声 SUSTAIN
0:22.5 ──┼── 8A → 8B 切换帧
         │   ★ 同一帧，劈砍木声末端 → 金属撕裂声开始
         │   ★ 这就是"音桥"——用同一段音波结构连接两个镜头
0:23.0 ──┤   8B 音效：金属撕裂声 SUSTAIN
0:24.0 ──┴── 8B 视频结束
```

#### 镜像剪辑的"听觉对位"规则

每对镜像剪辑（#3-#4, #5, #9-#10, #13-#14, #15-#16）的音效必须做到：
- **节奏完全相同**（步伐数、闷哼时长、风声频率）
- **音调略有差异**（A 线偏暖偏闷，B 线偏冷偏锐）

这样观众潜意识接收"两条线在同步"，但意识上不会觉得重复。

### 4. 关键静音点（Silence Beats）

静音是声音设计中最贵的资源。本片有 3 个关键静音：

| 时间 | 时长 | 作用 |
|------|------|------|
| 0:33.0 – 0:33.5 | 0.5s | 雷后回响，让观众"喘气" |
| 0:50.5 – 0:51.0 | 0.5s | 战士回头看苦工的瞬间，时间凝固 |
| 0:58.0 – 0:58.5 | 0.5s | 字幕浮现前，主题落定 |
