### BGM 后期处理

- 三段拼接处用 **0.5 秒交叉淡化（crossfade）**
- B 段中的 0:30-0:33 雷霆停顿可以**直接静音 BGM 0.5 秒**，让雷声独立
- 整体 BGM 音量在 -18 LUFS（让对白和音效有空间）

## 三、Track 2：对白（Dialog）

全片**只有 2 句对白**，都来自魔兽原版语音 + 后期处理。

| 时间 | 角色 | 台词 | 处理 |
|------|------|------|------|
| 0:53.0 – 0:54.5 | 格罗什 | "Work, work." | 加呼吸 + 略带笑意 + 压低 -3dB |
| 0:55.5 – 0:56.5 | 洛卡 | "For the Horde." | 加点头停顿 + 略带沙哑 + 提 +2dB |

### 操作步骤

1. 从 War3 / WoW 客户端语音文件夹找原版 wav（或网上下载语音包）
2. 用 Audition / Audacity 处理：
   - 加 **EQ**：降 200Hz 浑浊，提 3kHz 清晰度
   - 加 **轻微混响**（篝火夜营地空间感）
   - 加 **压缩**（动态范围控制）
3. 如果游戏原版语音不够好，用 **ElevenLabs Voice Clone** 重录：
   - 训练样本：游戏原版的 5 个不同情绪片段
   - 输出 prompt："weary orc peon, deep voice, slight smile, low tone"

### 备选 ElevenLabs 重录 Prompt

```
Voice profile: Aged orc warrior, deep gravelly voice
Emotion: Weary but warm, slight smile

Line 1 (Grosh):
"Work, work."
[pause: brief inhale before speaking]
[delivery: low, sandy, with quiet amusement]

Line 2 (Lok'ra):
"For the Horde."
[delivery: low, firm, with a nod implied in the rhythm]
```

### 关键音桥（必须做对）

#### 音桥 1：#8A → #8B（核心主题镜）

```
0:21.0 ─── 8A 视频开始
0:22.5 ─── 8A → 8B 切换帧
           ★ 这一帧的音频处理：
           - 8A 的劈砍木声尾部 reverb tail 持续
           - 8B 的金属撕裂声 attack 起音
           - 两者在波形上"无缝拼接"
           - 听觉效果：像同一个动作在两个时空发生
0:24.0 ─── 8B 视频结束
```

#### 音桥 2：#9 → #10（受伤镜对位）

```
两次闷哼必须用同一个声优录两遍：
- #9 闷哼：0:25.0，时长 0.4s，频率 200Hz
- #10 闷哼：0:28.0，时长 0.4s，频率 200Hz
两次音调、时长、强度完全一致
观众潜意识接收到"这是同一个声音"
```

- 频率：60 Hz 低频
- 节奏：每秒 1 次
- 音量：-35 dB
- 持续：0:38 – 0:41

## 七、混音规范（Mix Standards）

### 整体响度

- **最终母版**：-14 LUFS（YouTube / B 站标准）
- **抖音 / 视频号版**：-12 LUFS（移动端响一些）
- **峰值限制**：-1 dBTP（防止削波）

### 各轨道相对音量

| 轨道 | 平均音量 | 备注 |
|------|---------|------|
| BGM | -18 LUFS | 给对白和音效让位 |
| 对白 | -12 LUFS | 全片最响 |
| 环境层 | -28 LUFS | 衬底 |
| 动作层 | -20 LUFS | 中等突出 |
| 情绪层 SFX | 视情况 | 雷声 -8 LUFS（最响），静音段降到 -45 |

### 频段分配（避免互相冲突）

```
Bass (低频) 20-200Hz   ─→ 战鼓、雷声、心跳
Mid-Low 200-1k         ─→ BGM 主旋律、对白基频
Mid 1k-3k              ─→ 对白清晰度、铁器
Mid-High 3k-8k         ─→ 木屑、皮革、风
High 8k+               ─→ 火焰噼啪、雨点、号角泛音
```
